# College Chatbot

This chatbot is designed to help students, teachers, parents, and outsiders with common queries related to the college, such as fee payment, course registration, exam schedules, and more.

## Features:
- Role-based responses (student, teacher, parent, outsider).
- Integration with OpenAI GPT for intelligent responses.
- Cloud-based deployment with AWS Lambda (future feature).

## How to Run:
1. Install dependencies:
    ```
    pip install -r requirements.txt
    ```
2. Run the app:
    ```
    python main.py
    ```

## Technologies Used:
- Python
- Flask
- OpenAI GPT
